# 이유식 식단·큐브

아이폰 홈 화면에 설치해 쓰는 이유식 식단표·큐브 재고 앱입니다. 앱 화면은 이 저장소에서 GitHub Pages로 배포되고, 기록은 **별도의 비공개 저장소**(`babyfood-data`)의 `data.json`에 저장됩니다. 이 공개 저장소에는 아기 이름·식단 같은 개인 정보가 들어 있지 않습니다.

- 식단표: 하루 1끼/2끼, 곡류·단백질·채소·과일·알레르기 드롭다운 수정, 먹음 체크 시 큐브 자동 차감
- 큐브 현황: 제작일별 재고, −/+ 로 사용·되돌리기
- 필요수량: 기간별 필요 큐브, 소진 예상일, 만들 차례
- 알레르기: 노출 날짜·횟수, 재료 도입 기록

## 처음 연결
1. 비공개 저장소 `babyfood-data` 만들기
2. Fine-grained 토큰: 저장소 `babyfood-data` 만 선택, Repository permissions → Contents: Read and write
3. 앱 주소를 열고 GitHub 아이디·저장소 이름·토큰 입력 → 연결하기
4. 설정 → 가족 초대 링크 복사 → 가족에게 전송 (링크에 토큰이 들어 있으니 가족에게만)

여러 기기가 15초 간격으로 동기화되고, 동시에 고친 경우 바뀐 항목끼리 합쳐서 저장합니다. 모든 변경은 `babyfood-data` 저장소에 커밋으로 남습니다.
